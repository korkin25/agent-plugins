# Reference style for the report

Write one reference per line in exactly this pattern:

    [n] Authors (Year). Title. Journal, Volume(Issue), first–last.

1. Authors: each author as the surname, one space, then the initials, each initial followed by a period and no
   spaces between initials, e.g. "Fairley J.R.". Separate authors with a comma and a space; do not use "and" or "&".
2. Four or more authors: write only the first author followed by " et al.", e.g. "Fairley J.R. et al.".
   Three or fewer authors: list all of them in the original order.
3. Surname particles such as "van der", "von" and "da" are part of the surname: keep them in front of the surname,
   in lowercase, e.g. "van der Linde P.J.".
4. Title exactly as given in the list, without surrounding quotation marks, followed by a period.
5. Journal name in full, as given in the list.
6. Pages: the full first and last page joined by an en dash (–, U+2013), not a hyphen. Abbreviated ranges are written
   out in full: 317-24 becomes 317–324.
7. Duplicates: entries with the same title and year describe the same work; list it once.
8. Order: sort by the first author's surname exactly as written, particles included, ignoring letter case (so
   "van der Linde" sorts under v); for the same first-author surname, by year, oldest first. Then number the
   references [1], [2], … in that order.
