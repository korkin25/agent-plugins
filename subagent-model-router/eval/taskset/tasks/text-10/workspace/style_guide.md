# Orbit Notes documentation style guide

Apply every rule below to headings and body text alike. Change nothing that the rules do not cover.

1. Write "email", never "e-mail".
2. Write "website", never "web site".
3. Use "sign in" wording instead of "log in" wording: "log in" becomes "sign in", "logged in" becomes "signed in".
4. The product name is always written "Orbit Notes" (two words, both capitalized). Fix variants such as "OrbitNotes" or "Orbit notes".
5. Write the whole numbers 1 to 9 as words (one, two, three, four, five, six, seven, eight, nine). Exceptions, which keep their digits:
   - a number immediately followed by one of these units: MB, GB, ms, %;
   - version numbers such as 3.1.0 or 3.x;
   - dates.
   Numbers of 10 and above always stay as digits.
6. Write dates as "Month D, YYYY" with the full English month name and no leading zero, for example 2026-11-07 becomes "November 7, 2026".
7. Headings (lines that start with #) use sentence case: capitalize only the first word and the product name Orbit Notes; every other word is lowercase.
8. When a rule replaces the first word of a sentence, list item or heading, the replacement starts with a capital letter (for example "Web site" becomes "Website").
