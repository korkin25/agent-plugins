All 28 cases produced the same final routed tier in both formats, both repeats. Two code-test addition cases
(S03/S04) were routed light where labels expect standard. Incident drafting without permission to send (L07)
and documentation with an already-redacted placeholder (C05) were over-routed heavy where labels expect

execution failure. Raw-tier/risk probabilities changed without changing the final routing decisions.

## Interpretation

This experiment does **not** demonstrate improved routing accuracy from more context. Full text preserves
information the old extractor dropped, but the current model/questions/thresholds did not turn that into
better final choices on this small dataset. No risky task was under-routed in this set; that is not a safety
guarantee. Repeats are correlated, not 56 independent tasks; identical answers can involve provider caching.
No statistical significance, real task success, token savings or downstream quality claim is warranted.

Keep full text per owner choice. Future evaluation should add independently labelled, representative cases
where omitted constraints are decisive and compare question/threshold changes on a separate held-out set.
Do not tune this frozen set and report it as an unbiased test. Existing `risky` question may conflate dangerous
subject matter with authorized side effects; that requires its own controlled comparison.

## Reproduce (agent operation)

Use eval/run.py with --live --repeats 2 and a new output filename, through the already configured provider key.
The runner refuses overwrite, never prints key/headers, and stores only IDs, sizes/digests, probabilities,
latency and numeric usage. --live is explicit; without it only payload sizes are collected. Public results
are synthetic only. Details: cases.json, README.md and results-20260925-full-text.jsonl.
